# Temple Mudslide — Manual Walkthrough

A hands-on guide to the one-flare climb, upper checkpoint and slope-load crossing. Follow the visual cues and key releases below; no automation or Cheat Engine is needed to perform these inputs. The upper crouch was reached by the player using these cues. The complete recorded demonstration used telemetry for its pauses, so the seed-load timing described below still needs practice and is not a fully validated visual timing rule.

## At a glance

**Load start → square up by sliding → four left, two empty, one left, one empty → climb with the same flare → count head nods → pause during pickup → crouch-buffer to the dip → save through the passport → load the slope seed → reload the upper save while sliding → let Lara cross → walk out.**

Use physical **slot 1** for the start, **slot 3** for the replacement slope seed and **slot 4** for the upper checkpoint. Leave slots 1–3 intact. Slot 2 contains an old seed made with a jump; do not use it for this route.

## 0. Prepare the replacement slope seed, if needed

Skip this step if slot 3 already contains the calibrated 3095 seed.

Part 1 shows the local approach in **room 35**, near sector **8/15**. Lara climbs onto the low stone ledge, turns and moves onto the slope, then faces downhill. The measured seed starts on sector 7/15 and slides into 8/15; both are the steep section used here.

1. Use the local ledge and slope approach shown in Part 1, approximately **00:00–00:24**. Do not add a jump to reach the slope. The video is a local reference, not a documented complete route from level spawn.
2. Begin sliding downhill on the steep section. Open inventory, use the passport's save page and save this seed in **slot 3**. The demonstrated save sequence is around **00:25–00:36**.
3. Keep slot 3 for this seed. Saving resumes gameplay; the subsequent runout is normal.

A newly made seed can start at a different point in the slide and therefore change the later F9 timing. Merely using the same room or giving the save the same name does not recreate the exact calibrated seed. The video has no key overlay, so it cannot independently certify every input of the approach.

## 1. Load the start and face the lower slope

Reference: Part 2, **00:00–00:14**.

1. Load **slot 1 / 3089**.
2. Turn to face roughly uphill toward the mud slope, as shown in the video.
3. Hold **G+Up** to walk into the slope until Lara stops advancing. Release the keys.

You only need a rough uphill facing here; the next slide establishes the square alignment. Start from the same lateral position as the reference. Turning correctly does not correct a sideways offset along the slope.

## 2. Use one flare to square Lara to the slope

Reference: Part 2, **00:14–00:28**.

1. Tap **Comma once** to draw a flare. Wait until the draw animation finishes.
2. Hold **Y**. Once Lara is crouching, add **E+Space**, keeping **Y+E+Space** held together. The repeated drop-and-pickup motion begins to move her up the slope.
3. Climb only a short distance. The measured example used about **eight seconds**; watch the motion instead of treating that duration as exact.
4. **During a pickup**, release the keys and let the pickup finish. Let Lara slide back down without steering. Releasing just after dropping the flare can leave the flare behind; you want her to finish with it in hand.
5. Wait until she stops and stands. The slide has squared her facing to the slope.
6. Hold **G+Up** again until she stops against the slope. Release everything and open inventory with **Esc**.

Keep this same flare for the main climb. Do not press Comma again. The player also reported squaring up by sliding without spending a flare, but a repeatable no-flare access sequence was not documented; the one-flare method above is the recorded reference.

## 3. Learn the menu-buffer motion

A buffer briefly allows gameplay between closing and reopening inventory. It is a complete close-and-reopen cycle, not simply a tap of the direction key inside the menu.

1. Start with inventory **fully open** and all keys released.
2. Tap **Esc**, then release it.
3. **While inventory is still closing**, press Esc again together with the desired gameplay key.
4. Keep that second press held until inventory has reopened.
5. Release all keys before the next buffer.

Think of a quick double press of Esc: add the gameplay key on the second press and hold that second press. Do not wait for normal gameplay to become fully visible.

| Buffer type | Second press |
| --- | --- |
| Left buffer | Left+Esc |
| Empty buffer | Esc alone |
| Crouch buffer | Y+Esc |

In the successful trials, each buffer advanced two animation steps. A slower attempt advanced three. This is why counting the cycles is useful only when the closing/reopening rhythm is consistent. The automation used roughly 180 ms between the starts of its Esc presses; that is a reference measurement, not a proven human timing window.

## 4. Set the climbing angle: 4–2–1–1

Reference: Part 2, **00:28–00:43**.

With inventory open after the square alignment, perform these **eight complete buffers**:

| Buffer | Second press | Say to yourself |
| --- | --- | --- |
| 1 | Left+Esc | Left one |
| 2 | Left+Esc | Left two |
| 3 | Left+Esc | Left three |
| 4 | Left+Esc | Left four |
| 5 | Esc alone | Empty one |
| 6 | Esc alone | Empty two |
| 7 | Left+Esc | One more left |
| 8 | Esc alone | Empty; finished |

**Four left, two empty, one left, one empty.** Release the keys after every reopening. The two consecutive empty buffers let the turn-stop motion finish before the small extra turn. Do not replace this with one long left hold.

After the eighth buffer, close inventory normally. You are now ready for the main climb. If you lose count or suspect a slow buffer, re-establish the square alignment and repeat instead of guessing an extra turn.

## 5. Climb and count Lara's head nods

Reference: Part 2, **00:43–01:22**.

1. Hold **Y** until Lara crouches.
2. Add **E+Space** and keep **Y+E+Space** held. Use the flare already in her hand.
3. Watch **Lara's head** and count its repeating **nodding motion** during this main climb. Do not count the large full-body bends instead, and do not carry over your count from the short alignment climb.
4. Approximately **28 head nods** helped the player recognize the stopping rhythm. Treat that as an approach cue, not a guarantee that the pose is correct. Her appearing closer to the camera was another useful height cue; no fixed head size or screen position was calibrated.
5. Near the top, pause **while the pickup is still in progress**: release **E and Space completely**, keep **Y held**, and press **Esc**.
6. Once inventory is open, release **Y and Esc**. Leave inventory open.

**Do not wait for the pickup to finish and the downward slide to begin.** The aim is to freeze during the upper pickup so you can advance to the target pose one buffer at a time. If the 28-count does not look like the reference height, check the starting position, the count and the alignment instead of forcing the next step.

## 6. Crouch-buffer to the short downward dip

Reference: Part 2, **01:22–01:57**. See the comparison images in the HTML version of this walkthrough.

1. From the open inventory, perform **one crouch buffer**: tap/release Esc, then press and hold **Y+Esc** while the menu closes.
2. Release both keys after inventory reopens.
3. Inspect Lara's pose before doing another buffer.
4. For the player's manual starting pause, count **15 crouch buffers first**. Then watch the **next buffer — number 16 — for the short drop in height**: Lara's body visibly lowers and her hands appear to disappear into the slope. This drop after the first 15 buffers is the key stopping cue.
5. **Stop immediately at that dip. Keep inventory open.** Do not add one more buffer to be safe.

**Manual rhythm: 15 buffers → one more → Lara drops lower → stop with inventory open.** Inspect each reopening, including the first 15; if the dip occurs earlier because your starting pause differs, stop at the dip rather than adding buffers to reach a number.

The successful human attempt took **16** two-step crouch buffers from its particular initial pause. The automated demonstration took **19**, because it paused earlier in the pickup. Neither number is a universal instruction from an arbitrary pause. Starting on a different animation step can change the count or skip the brief target pose. The images below show the automated sequence immediately before and after the same height drop; their labels 18/19 do not replace the manual count 15/16.

Use the downward change between consecutive poses, not just “I cannot see her hands.” The inventory overlay and ground can hide the hands at other moments too. Both comparison screenshots use the same inventory overlay; the final image does not require F5.

## 7. Save the frozen pose through the passport

Reference: Part 2, **01:57–02:10**.

Do this **without closing inventory back into gameplay**. Do not close with Esc and then try to catch the pose using F5.

1. With the dip still frozen in inventory, press **Down** to switch to the options ring.
2. Select the passport, labelled **Game / Spiel**. It was already selected after Down in the tested menu; check what is selected on your screen.
3. Press **Enter**. The tested first page is **Load Game / Spiel laden**.
4. Press **Right once** to reach **Save Game / Spiel speichern**. Read the heading before confirming anything.
5. Use Up/Down to select **physical slot 4**. Preserve the start and both seeds in slots 1–3.
6. Press **Enter** to save. Remember the new counter attached to slot 4.

The menu closes after saving and Lara may slide down. That is expected: the upper crouch has already been stored. Continue with the load sequence; do not try to salvage the resumed slide by climbing again.

## 8. Load the steep seed, then reload the upper checkpoint

Reference: Part 2, **02:11–02:31**.

1. Open **F9** and load **slot 3 / 3095**, the replacement room 35 seed.
2. Let Lara **actually move downhill in the slide**. Do not immediately reopen the load menu before any sliding motion.
3. Open **F9 while she is still on the steep section**, before the flatter runout. Compare the brief sliding interval around **02:18** in Part 2. This step follows soon after loading, not after a long slide to the bottom.
4. In the load list, select the **new upper save in slot 4** and confirm. This is 3097 in the final recording; use your own newly created counter.
5. Release the keys and let Lara automatically cross the upper edge and come to a standstill. Do not steer or walk during this crossing.

The new seed uses room 35, sectors 7/15–8/15. Do not reuse timing from the old room 98 / 3088 seed. The automatic run selected the F9 pause from live state measurements; a precise repeatable screen landmark for unaided human timing has **not** been validated. The practical rule here is “actual slide, still on the steep section,” with the video as a reference. If the crossing fails, retain your upper checkpoint and retry the seed-to-upper load sequence; do not overwrite the useful upper save with a failed pose.

## 9. Walk out and stop

Reference: Part 2, **02:31–02:42**.

1. Wait until Lara has finished the automatic crossing and is standing above the slope.
2. Make a short **G+Up** walk, then release and let her settle.
3. Make a second, shorter **G+Up** walk and release again. The measured example used approximately **0.4 seconds** for the first walk and **0.25 seconds** for the second, with a settling pause between them.
4. Compare the final standing position with the endpoint in Part 2. This is the position identified as **room 148** by the measurements. You can open inventory to hold the endpoint for inspection or recording.

These are short walk inputs, not a jump or a long forward run. The second 0.25-second interval is another walk, not the duration of the settling pause. The ordinary game view does not display a room number, so use the video as the practical visual reference; the numeric room identification comes from the recorded analysis.

## If something goes wrong

| Symptom | What to do |
| --- | --- |
| Windows Start menu opens | Bind Action to E; release Ctrl before any Esc input. |
| Flare is left behind after the short climb | Release during a pickup and let it complete before the alignment slide. |
| Lower angle looks wrong | Slide to square up again; repeat the full 4–2–1–1 sequence with clean releases. |
| Lara slides before you can pause near the top | Open inventory earlier during the pickup. Release E+Space, retain Y, then press Esc. |
| About 28 nods does not match the reference height | Recheck starting position and head-nod counting; do not substitute full-body bends or use the count alone. |
| The upper pose changes too far with each buffer | Your second Esc press may be late; practise reopening during the closing animation. |
| You can see the downward dip | Stop buffering. Save through the still-open inventory passport. |
| You passed the dip | Do not save a different pose as though it matched. Rebuild the upper approach and pause again. |
| Lara slides after saving | Normal: the pose is already saved. Load the seed, then your new upper checkpoint. |
| No upper crossing after the load sequence | Check that you loaded the new slot 4 checkpoint and paused the seed during the steep slide. Retry from slot 3. |

## Compact practice card

**Start:** slot 1. **Seed:** slot 3. **Upper:** slot 4. Preserve slots 1–3.

**Align:** walk into slope → draw one flare → short Y+E+Space climb → release during pickup → slide square → walk back into slope → inventory.

**Angle:** 4 left buffers → 2 empty → 1 left → 1 empty → close inventory.

**Climb:** Y, then add E+Space → count head nods, about 28 as an aid → during upper pickup release E+Space → keep Y and press Esc → release when open.

**Upper:** individual Y+Esc buffers → inspect every pose → with the player's starting pause: 15 buffers, then the 16th produces the height drop → stop immediately and leave inventory open.

**Save:** Down → passport → Enter → Right to Save → slot 4 → Enter.

**Finish:** F9 → slot 3 → actual steep sliding → F9 → new slot 4 → hands off during crossing → short walk, settle, shorter walk → endpoint.

## Evidence note

This walkthrough consolidates the player's documented manual cues, the successful human upper-pose trial, the current replacement-seed procedure and the two delivered videos. Approximately 28 nods, the body dip and hands entering the slope are player-observed cues; they are not guarantees for arbitrary starting positions. The 16-versus-19 buffer distinction is deliberate. The fully automated result verifies completion with telemetry assistance, not universal human timing. Detailed measurements and historical limitations remain in the proof archive's PLAYER_GUIDE.md, MANUAL_SETUP.md and current run journal.
