# Temple Mudslide — Delivery Package

The illustrated guide, videos, manual walkthrough and proof are available as static HTML pages.

## View locally

Open `START_HERE.html` in a browser. Keep the videos and archives beside it.

## Publish with GitHub Pages

1. Commit and push this folder's files to `main`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/ (root)**, then **Save**.
5. Once deployment completes, use the website link displayed by GitHub Pages.

Expected website address after deployment:
<https://MarkSchareina.github.io/tr3-temple-mudslide-delivery-package/>

`index.html` opens the existing `START_HERE.html`. The standalone proof and manual walkthrough remain linked from that page. The `.nojekyll` file serves the files as static content.
